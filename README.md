# Memory Game

Браузерная игра «найди пару» на чистых HTML, CSS и JavaScript, без сборки и
зависимостей. 16 карточек (8 пар), счётчики ходов и пар, таблица лидеров в
`localStorage`.

## Запуск

Откройте `index.html` или поднимите статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```
